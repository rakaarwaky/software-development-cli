# CONTRIBUTING — software-development-cli

## Workflow

| Step | Action |
|------|--------|
| Branch | `feature/<topic>` or `fix/<topic>` |
| Commit | `type(scope): description` (e.g. `feat(host): add subdir validation`) |
| PR | Open against `main`, one feature per PR |
| Review | CI must pass: lint + tests |

## Commit Convention

| Prefix | Meaning |
|--------|---------|
| `feat` | New feature |
| `fix` | Bug fix |
| `refactor` | Code restructure |
| `docs` | Documentation only |
| `test` | Test additions |
| `chore` | Build/CI/tooling |
